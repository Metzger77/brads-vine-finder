# Brad's Vine Finder

A personal Amazon Vine search launcher designed for fast item discovery.

## Features

- Personalized categories and broad discovery searches
- Favorites, Most Picked, and Good Find / No Luck feedback
- Search links open in the same tab by default, with an optional new-tab setting
- Tool-brand searches, John Deere 420 / 318 / 430 searches, and other tailored terms
- Compact layout with expanded categories and quick search controls

## Run locally

Open `index.html` in a web browser. The project is self-contained and does not require a build step.

Search preferences, favorites, and ranking activity are stored locally in your browser, so they do not sync across devices or transfer when you open the page elsewhere.
